# NAY CHI — Web Developer & Digital Solutions Portfolio

A responsive one-page portfolio website inspired by the uploaded Designer/Coder reference.

## Included
- Modern black/white creative developer theme
- Designer × Developer hero
- About + NCC Education section
- 7 project cards based on the projects you described
- Project category filters
- Client "Choose the solution" section
- Services
- Experience
- Skills/toolkit
- Contact section
- Mobile responsive layout
- No external JavaScript framework required

## Run locally
Open `index.html` in a browser.

## Customize before publishing
1. Replace `your@email.com` in `index.html`.
2. Replace GitHub / LinkedIn / Viber `#` links.
3. Add real screenshots to each project card later.
4. Update technology names to match your actual skills.
5. If a project is only a concept or school project, keep wording such as "concept" or "project" rather than implying client ownership/production use.

## Deploy
This is a static site and can be deployed to Netlify, Vercel, GitHub Pages, or any static hosting service.
